# Модуль `:ai`

Библиотека диалога: без HTTP и без базы. Главный вход — `AgentTurn.handle`: черновик, реплика, справочник, сегодняшняя дата, список кампаний и роль на входе; ответ ассистента, новый черновик и, может быть, `CommitRequest` (просьба к серверу записать) на выходе. Пока обязательные поля не заполнены, ведёт автомат: код разбирает даты (`DateParser`), справочник (`TextExtractor`), ответы кнопками (`QuickAnswer`) и задаёт один вопрос за раз (`Questions`), а модель достаёт остальное в JSON (`IntentParser`). Когда поля заполнены, `DesignAgent` даёт модели инструменты: `update_draft`, `generate_banner`, `edit_banner`, `generate_image`, `check_compliance`, `ask_user`, `show_draft`. Пишущих инструментов нет. `Compliance` проверяет баннер по 38-ФЗ «О рекламе» (правила в коде + ИИ-юрист). `ModeratorTurn` — чат модератора.

Вызывает модуль `:server` (`JobProcessor`). Модель — интерфейс `LlmClient`: `OpenAiCompatibleClient` для llama.cpp/vLLM/GigaChat-прокси, `MockLlmClient` для работы без сети. Картинки — `ImageGenClient` (`OpenAiImageClient` для `/v1/images/generations` или `sdapi`, `PlaceholderImageGen` для тестов) и `ImageRequests` (асинхронная очередь, реализует сервер). Все промпты — в `prompt/Prompts.kt`, в клиентах их нет.

Сборка и проверка: `cd backend && ./gradlew :ai:ktlintCheck :ai:test` (на Windows `gradlew.bat`). Ручек у модуля нет — это библиотека; сценарий из презентации целиком прогоняется в `AgentTurnTest.demoScenario`.
