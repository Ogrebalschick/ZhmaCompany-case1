# Чат сборки кампаний

Один экран: шапка с ролью, лента ответов ассистента и поле ввода. Сервер и промпты живут отдельно. Карта файлов — в корневом `frontend-structure.md`.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Открывается `http://localhost:5173`. Запросы на `/api` проксируются на `http://localhost:8080`.

По умолчанию в разработке включены локальные ответы (`VITE_USE_MOCK=true` в `.env.development`): сервер не нужен. Чтобы ходить в API, создайте `frontend/.env.local`:

```bash
VITE_USE_MOCK=false
```

Каждый запрос отправляет заголовки `X-User: ivanov.p` и `X-Role` (`campaignManager` или `campaignModerator`). Смена роли в шапке не создаёт новую сессию.

## Что видно на экране

- Пустая лента предлагает один бриф про вклад и Москву.
- Пока задача в `PENDING`, поле заблокировано и виден статус «Собираю ответ».
- Блоки ответа: черновик, быстрые ответы, предложение тега или места, превью баннера, список кампаний, предупреждения.
- Неизвестный `type` пропускается, текст ответа остаётся.
- Справа закреплён последний черновик. Кнопка «Сохранить» отправляет текст `подтверждаю`.
- Ошибка сети или `FAILED` появляется в ленте.

Enter отправляет, Shift+Enter переносит строку.
