# Экран `frontend`

Точка входа: React + TypeScript + Vite, чат менеджера и модератора. Слева — новая кампания, черновики и сохранённые кампании со статусами; панель можно сузить в пределах лимита или свернуть до значка. Длинные названия обрезаются многоточием. Под заголовком «Кампании» переключатель «Мои / Все»: «Все» добавляет чужие кампании с именем автора, если они есть в базе. Кнопка «Сохранить» справа недоступна, пока сохранённая кампания без новых правок. В центре — диалог и меню ответа над полем ввода (`QuickReplyBar`, одиночный и множественный выбор). Рядом с макетом баннера показывается промо-экран из тех же полей. Поле само растёт на несколько строк, отправка — иконка внутри него. Справа — карточка черновика со статусом кампании и признаком показа. Блоки ответа рисуются по `type`: `campaign_draft`, `quick_replies`, `creative_preview` (баннер, картинка, увеличение, скачивание), `compliance` (проверка по 38-ФЗ), `entity_proposal`, `campaign_list`, `warnings`. Промптов и логики кампании на экране нет.

Повторное открытие кампании возвращает тот же диалог: запросы менеджера остаются в сессии. Новый чат не запрашивает пустую историю. Пока список кампаний или уже идущий диалог грузятся, виден индикатор, а не пустая заглушка.

## Куда идти

- Оболочка и ширина панелей: `src/App.tsx`, `src/components/layout/AppShell.tsx`
- Список кампаний и черновиков: `src/components/sidebar/Sidebar.tsx`
- Диалог и индикатор открытия: `src/components/thread/MessageList.tsx`
- Макет баннера и промо-экран: `src/components/blocks/CreativePreview.tsx`, `src/components/blocks/PromoScreen.tsx`
- Поле ввода: `src/components/composer/Composer.tsx`
- Сессии и повторное открытие кампании: `src/chat/useChat.ts`

Ходит только в `:server` через прокси Vite `/api` → `http://localhost:BACKEND_PORT`. Номер сессии хранится в `localStorage`, обновление страницы открывает тот же чат. `VITE_USE_MOCK=true` в `.env` включает ответы из `src/mock` без сервера.

Запуск: `cd frontend && npm install && npm run dev` (порт `FRONTEND_PORT` из корневого `.env`, по умолчанию 5173), сборка и проверка: `npm run build && npm run lint`. Под Windows проще `start.bat` в корне: он поднимет сервер и экран сам.
