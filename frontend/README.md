# Чат сборки кампаний

## Что это

Один экран: шапка с ролью, лента ответов ассистента, поле ввода и боковой черновик. Промпты и автомат живут на сервере. Карта файлов — в корневом `frontend-structure.md`.

## Кто вызывает

Экран открывает человек. Запросы идут в `:server` через прокси Vite. Сервер этот пакет не импортирует.

Каждый запрос отправляет `X-User: ivanov.p` и `X-Role` (`campaignManager` или `campaignModerator`). Смена роли в шапке не создаёт новую сессию.

## Как запустить

```bat
cd frontend
npm install
npm run dev
```

На Unix те же команды `npm`. Открывается `http://localhost:5173`. Запросы на `/api` проксируются на `http://localhost:8080`.

В разработке мок выключен: `VITE_USE_MOCK=false` в `.env.development`, нужен запущенный сервер. Чтобы обойтись без него, создайте `frontend/.env.local`:

```bat
VITE_USE_MOCK=true
```

## Как проверить

```bat
npm run build
```

Это `tsc --noEmit` и сборка Vite.

## Что видно на экране

- Пустая лента предлагает один бриф про вклад и Москву.
- Пока задача в `PENDING`, поле заблокировано и виден статус «Собираю ответ». Опрос раз в секунду, не дольше 110 попыток.
- Блоки ответа: черновик, быстрые ответы, предложение тега или места, превью баннера, список кампаний, предупреждения.
- Неизвестный `type` пропускается, текст ответа остаётся.
- Справа закреплён последний черновик. Кнопка «Сохранить» отправляет текст `подтверждаю`.
- Ошибка сети, тело `{ "errors": [{ "message" }] }` или `FAILED` появляется в ленте.

Enter отправляет, Shift+Enter переносит строку. Превью баннера — вёрстка по текстовым полям, не картинка модели.
